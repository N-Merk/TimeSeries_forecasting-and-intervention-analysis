# P1 — Airline Passenger Forecasting

This project demonstrates time series analysis and forecasting using the monthly Airline Passengers dataset.

The code explores the series through visualizations, autocorrelation plots, and seasonal decomposition. It then prepares training, validation, and test data, trains a Long Short-Term Memory (LSTM) neural network, and compares its forecasts with observed passenger numbers.

The folder includes Python notebooks and a Python script, as well as generated plots and reference material.

Some plot labels and other project materials are in Portuguese. This README is in English.

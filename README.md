# Time Series Projects

This repository contains two projects exploring time series analysis and forecasting.

## P1 — Airline Passenger Forecasting

P1 uses the monthly Airline Passengers dataset to demonstrate time series visualization and forecasting with a Long Short-Term Memory (LSTM) neural network. The code explores trends, seasonality, autocorrelation, and seasonal decomposition, then prepares training, validation, and test data, trains the model, and compares its predictions with observed passenger numbers.

The project includes Python notebooks and a Python script, along with generated plots and reference material.

## P2 — German Electricity Consumption

P2 analyzes monthly electricity consumption in Germany using data from Open Power System Data. Its Python script downloads and processes the source data, explores seasonal patterns, tests for stationarity, compares and estimates SARIMAX models, and examines intervention effects, including changes around the COVID-19 period. It also includes residual diagnostics and forecasts, with plots generated for the analysis.

The project includes a Python script, a notebook, and a written report.

# P2 — German Electricity Consumption

This project analyzes monthly electricity consumption in Germany using data from Open Power System Data.

The code downloads and processes the source data, explores seasonal patterns, tests for stationarity, and estimates SARIMAX models. It also examines intervention effects, including changes around the COVID-19 period, performs residual diagnostics, and generates forecasts and plots.

The folder includes a Python script, a notebook, generated figures, and a written report.

Some code comments, plot labels, and report materials are in Portuguese.
